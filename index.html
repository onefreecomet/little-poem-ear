使用小贴士

  • 想让孩子跟着读：把「句间停顿」调到 3 秒或 5 秒，留出跟读时间。
  • 一直循环磨耳朵：打开「循环」按钮，把手机自动锁屏时间调长，再连上蓝牙音响。
  • 只想听几遍就停：选「播放次数」3、5、10、20 次，放完自动停下休息。
  • 默认用「小米·冰糖」：最像真人的温柔女声，首次每句要联网合成几秒，之后循环就顺。
  • 如果小米语音偶尔连不上，只有那一句会临时用系统语音顶上，后面的句子会继续用小米语音，设置不会被改掉。
  • 小米 MiMo 的 API Key 怎么拿（第一次用之前要做这一步，填一次就长期有效）：
    ①用手机或电脑打开 platform.xiaomimimo.com，用小米账号登录，没有就先用手机号注册一个。
    ②进左边「控制台」，找到 API Keys 页面。
    ③点「新建 / Create API Key」，生成的密钥是 sk- 开头的一长串。
    ④它只在创建那一刻显示一次，关掉页面就再也看不到了，当场复制存好（存微信收藏、备忘录都行）。
    ⑤回到本页，展开上面「小米 MiMo 语音」那个折叠框，粘进 API Key 输入框，点「保存配置」。
  • 拿到 Key 之后还有两点要知道：免费用量用完了，去同一个控制台的「余额」页面充值就能接着用；Key 分两种别填错，按量付费的是 sk- 开头（本页要的就是这种），Token Plan 订阅的是 tp- 开头，两种不通用。
  • 还没填 Key 也能用：页面会自动改用系统语音，只是没有小米那么像真人。把 Key 填进上面的输入框并点「保存配置」之后，再点一下「小米·冰糖」，就切到真人声音了。
  • 手机浏览器菜单选「添加到主屏幕」，下次就能像 App 一样直接打开。
